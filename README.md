# Thiệp Trung Thu – DLove style

Static web recreation of the interactive Mid-Autumn Festival card (inspired by t.dlove.vn).

## Live demo
Open the repo on GitHub Pages or just open `index.html` locally.

**Repo:** https://github.com/tnam17785/trung-thu-thiep

## Features

- Loading screen with glowing moon + text “Đang mở thiệp…”
- Night scene: starry sky, soft clouds, heart-shaped frame, full moon, floating sky lanterns, white rabbit on osmanthus branch
- **Ấn giữ vào mặt trăng** (long-press ~0.85s) to transition
- Second scene: dozens of floating texts “Trung thu vui vẻ” / “Iu em nhiều lắm”, lanterns, crescent + mini rabbit
- **Trượt / kéo** để xoay góc nhìn 3D (perspective rotateX/Y)

## How to run

```bash
# just open
open index.html

# or serve
npx serve .
# or
python -m http.server 8080
```

## Deploy

Any static host (GitHub Pages, Vercel, Netlify…).
